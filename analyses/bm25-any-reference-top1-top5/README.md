# 原始问题 BM25：Top1–5 至少命中一条参考原文

复用已冻结的 257 题原始问题、整段对话 BM25 排名；没有新检索、改写、模型调用或标签调整。

**主指标**：对每题，TopN 的来源 ID 与官方参考对话来源 ID 有至少一个交集。此前常报的“取齐”指该题所有官方参考对话均在 TopN。两者都按来源对话计，不是最终答题正确率。这里的“至少一条”不保证命中的就是回答所必需的那条，也不保证遗漏的事件已经找到。

Top5 时，201 题取齐全部官方参考，31 题只命中部分，25 题一条也未命中。旧25题早在 Top1 全部至少命中一条，因此只看“有无入口”会掩盖后来32/200题上的漏检。

此前 TopN 对比表统计的是**全部官方参考对话取齐**，严格说不是“全部真正必要证据”：参考来源可能包含背景、错误或可替代证据。单独按本实验预先审过的必要证据单元统计，排除事前标明有歧义的25题后，Top5 在232道清晰题中至少命中一个必要单元为212/232（91.4%），全部必要单元取齐为199/232（85.8%）。这里一个单元可以有多个替代来源，也可能需要多来源共同见证；分母与官方参考口径不同，不应直接比较两种百分比。

C037 是“至少一条不够”的真实例子：首轮 Top5 有 Evan 医院误会的参考对话，却漏 Sam 胃炎急诊与 Evan 心悸。P07 则说明官方参考取齐也不自动证明精确总数已穷尽。这些限制不改变本次纯来源 ID 统计。

`inputs.json` 固定每题原BM25 Top5、官方参考、预审必要单元与可评状态；`results.json` 给出逐题命中和分组汇总；`bindings.json` 记录上游文件 SHA256。独立重算：`python3 -B calculate.py --check`，只读取本目录的固定输入和结果，不调用模型或网络。重新从父实验生成输入：`python3 -B calculate.py --build`，会覆盖本目录输入与结果，不能用于验证已封存结果。

这三组题已被用于方法探索，并非新盲测。LoCoMo 的200题来自10份历史，不能视为200份独立历史。
