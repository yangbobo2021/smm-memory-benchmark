# Top N 是否包含完整回答证据

分析编号：**SMM-B001-TOPN-001**。沿用 SMM-B001 的 25 道题、同一批原文与冻结检索排名。2026-10-26 完成；**新增模型调用 0，向量计算 0**。原基线目录不变。

## 统计口径

- **主指标：每题的必要证据是否全部取齐。** 沿用基线 36 项必要信息标注，每项至少取到一个已登记的原文来源，才算覆盖；一题的所有必要信息都覆盖才算该题成功。不是“命中任意一段相关对话”。
- **附加指标：官方参考对话是否全部取齐。** 25 题共 43 次参考对话引用，包括旧状态、重复旁证等；全部参考取齐的要求可能比回答需要的证据更严格。例如 P10，一段对话已经同时说明两个项目，不一定需要另外两段分别提及同一项目的对话。
- Top N 的单位是**整段历史对话**，完整原文包含原有角色与时间信息。每道题的检索语料为 42～62 段对话。BM25 使用冻结的原始问题检索排名；向量使用基线的 MiniLM384 排名。没有改写关键词、重算分数、更换向量模型或引入 AI 重排。
- “两路各 Top N”指各取 N 段、按原文 ID 合并去重，**不是合并后只保留 N 段，也不是 50% 分数融合**。
- 复用已登记证据，不根据这次排名补写标注。统计的是**已标注证据覆盖率**，没有对所有其他候选是否存在语义等价旁证重新盲审。

完整协议：[protocol.json](protocol.json)。全部 25 题保留；P22/P25 的时间解释歧义不妨碍核查引用来源是否被取到。另附 23 道清晰题的相同指标，详见 [summary.csv](summary.csv)。

## 具体卡在哪里

- **BM25 Top3 缺 P08、P09。** P08 问调酒使用过几种柑橘，排名 3 的原文提供实际使用青柠的信息；还需要排名 4 的原文说明以前聚餐使用过橙子和柠檬。P09 问 12 月参加信仰活动的天数，三段分别提供 12 月 10、17、24 日活动，其中一段排第 4。
- **两路各 Top3 只缺 P08。** P09 的第三项信息被向量 Top1 补上，但 P08 的橙子和柠檬原文在两路均排第 4，合并两路前三依然缺。
- **向量 Top5 缺 P24 的唯一必要原文，实际排第 8。** 原句为 `I just got back from a networking event that ran from 6 PM to 8 PM today`，原文记录时间为 2022-03-09，用于结合提问时间计算已经过去几天。它在 BM25 排第 1。
- **向量 Top5 还少 P10 的一段官方重复旁证，但不缺回答必要信息。** Top2 中已有原句 `I've created separate boards for my thesis, Data Mining project, and Database Systems project.`，足以支持两个非论文项目；因此主指标是 24/25，严格官方来源指标是 23/25。

## 作为回答输入的取舍

| 方案 | 必要证据取齐 | 平均对话数 | 平均原文字符数 |
|---|---:|---:|---:|
| BM25 Top3 | 23/25 | 3.00 | 37,658 |
| BM25 Top4 | 25/25 | 4.00 | 49,139 |
| BM25 Top5 | 25/25 | 5.00 | 59,715 |
| 各 Top3 合并 | 24/25 | 4.32 | 53,247 |
| 各 Top4 合并 | 25/25 | 5.88 | 70,940 |
| 各 Top5 合并 | 25/25 | 7.52 | 88,256 |

字符数为完整原文 Unicode 字符数之和，不含提示、JSON 包装；**不是 token 数，也不是实测推理耗时**。各 Top4 去重后为每题 4～7 段，各 Top5 为 5～9 段。

在**本批固定题**上，BM25 Top4 是取齐全部已标注必要证据的最小单路 N；相比 Top5，平均原文字符少约 17.7%。如果维持双路方案，各 Top4 已经取齐，各 Top5 未增加已标注证据覆盖，平均原文字符却多；从各 Top5 改为各 Top4 可减少约 19.6% 字符。

因此可将 **BM25 Top4 / 双路各 Top4** 作为下一次回答验证的候选配置。各 Top3 适合作为允许继续检索的较省输入配置，但当前仍有实际遗漏。不能据此在真实 APP 中保证 Top4 足够，也不能判定向量没有价值：这是已知英语正例小样本，截点是在看过这些题后选择的。通用结论需要新留出题验证；实际回答效果与时间，还需要读者模型试验。这轮没有执行这些额外试验。

## 离线复现

Python 3.11+，标准库，无服务或密钥：

```bash
python3 -B analyses/top-n-evidence-v1/analyze.py --check
python3 -B tools/verify_publication.py
```

`--check` 重新读取冻结排名与原文，验证 51 个输入文件的哈希、全部来源正文哈希、39 条见证引用的原文位置/角色/时间、排名唯一性/递减顺序/语料归属、候选集合单调扩张，以及既有 Top5 统计的一致性，再逐字节比较三个结果文件。不覆盖原始结果。脚本直接读取来源排名，不使用截断片段排名。

`results.json` 保存完整逐题计算过程和输入 SHA256；`summary.csv` 保存两种分母切片、三种路线、五个 N 的汇总；`case-coverage.md` 提供人工检查入口。全部文件在原不可变基线目录之外，保持既有 750 条模型实验记录不变。
