# LoCoMo 文字证据敏感性分析

SMM-RG001 的原始 200 题成绩保持不变。本补充分析在看到排名后进行，使用的是**检索之前已保存**的 [图像元数据标记](../../experiments/smm-retrieval-generalization-001/provenance/modality-audit.json)，不新增检索、编码、模型回答或标签修订。

只看标注证据轮次**没有图像元数据**的 111 道题，全部官方参考对话取齐结果为：

| N | BM25 | 向量 | 两路各 Top N 合并 |
|---|---:|---:|---:|
| 1 | 59/111（53.2%） | 32/111（28.8%） | 67/111（60.4%） |
| 2 | 80/111（72.1%） | 46/111（41.4%） | 86/111（77.5%） |
| 3 | 84/111（75.7%） | 53/111（47.7%） | 90/111（81.1%） |
| 4 | 88/111（79.3%） | 62/111（55.9%） | 94/111（84.7%） |
| 5 | 94/111（84.7%） | 67/111（60.4%） | 99/111（89.2%） |

因此，原始 200 题中“BM25 Top4 没有全部取齐”的现象，不能只归因于文本索引缺少图片。当前 BM25 单路整体较强、向量局部补充的方向也保持。不过这不是新的独立随机样本；“有图像元数据”不等于一定需要图像才能回答，“无图像元数据”也不保证官方答案或证据完全正确。仍然只评价来源覆盖，不评价答案。双路合并允许更多输入。

另外 89 题的结果及全部案例编号也保留在 [results.json](results.json)。原始实验方法、限制与许可见 [SMM-RG001](../../experiments/smm-retrieval-generalization-001/README.md)。

python3 -B analyses/smm-rg001-text-evidence/replay.py --check
