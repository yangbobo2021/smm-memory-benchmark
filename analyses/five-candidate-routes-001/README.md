# 五种固定候选集合的回答依据覆盖对比

本分析复用已封存的原问题排名，不重新检索、编码或调用模型。比较整段对话的 BM25 Top5、向量 Top5、BM25 Top10、向量 Top10，以及 BM25 Top5 + 向量 Top5 去重并集。两路并集保留全部不同来源，不再截断为五条或十条。

**评价口径：**只使用 [SMM-SF-LUNA001](../../experiments/smm-sufficiency-luna-001/README.md) 在模型执行前审核的回答依赖标注。257 题中有 232 题可明确判断；另 25 题有歧义，分别来自原 25 题 2 题、新 LongMemEval 32 题 1 题、LoCoMo 200 题 22 题，均不进入下面的分母。一个依赖单位可能有多个可替代来源组合；来源组合内可能需要多段对话。本分析沿用原实验的单位判定函数，不重写标签。

- **至少一项：**一道题的候选满足至少一个依赖单位。
- **全部取齐：**一道题的候选满足它的所有依赖单位。
- **依赖单位覆盖：**所有题中命中的依赖单位总数 / 依赖单位总数；这是微平均，不能当作题目成功率。

## 分数据组

每格依次为“至少一项 / 全部取齐”，两者分母都是该组可明确判断的题数。完整的依赖单位覆盖数、候选数量和逐题来源 ID 在 [results.json](results.json)。

| 候选集合 | 原 25 题中明确的 23 题 | 新 LongMemEval 31 题 | LoCoMo 178 题 |
|---|---:|---:|---:|
| BM25 Top5 | 23/23 · 23/23 | 29/31 · 25/31 | 160/178 · 151/178 |
| 向量 Top5 | 22/23 · 22/23 | 26/31 · 25/31 | 119/178 · 106/178 |
| BM25 Top10 | 23/23 · 23/23 | 31/31 · 27/31 | 171/178 · 161/178 |

在“全部取齐”上，两路并集相对 BM25 Top10 **净少 3 题**：它取齐了 BM25 Top10 未取齐的 L011、L012、C035、C183，同时漏掉 BM25 Top10 已取齐的 L018、C059、C073、C111、C120、C168、C187。平均候选数 8.01 对 10.00，因此并集以较少候选接近 BM25 Top10，但目前不能说它的取齐率更好。向量 Top10 也有互补题，但总体低于 BM25 Top10。

本分析只评价**来源 ID 层面的预标注依赖覆盖**，不代表模型真的读懂了来源、判断信息充分，或回答正确。原 25 题和后续 32/200 题均已在此前实验使用；LoCoMo 的 200 题来自 10 份历史，不能当成 200 份独立历史。此处复用的向量模型、切片和排序实现不变，因此结论仅限这个已测配置，不代表所有向量检索。双路并集实际有 5–10 段不同对话，不是固定十段；本表同时列出平均候选数，便于判断覆盖与输入成本。

离线复算：在仓库根目录运行 `python3 -B analyses/five-candidate-routes-001/replay.py --check`。脚本核对 257 题的父排名、来源集合和原 BM25 Top5 与 SF-LUNA001 输入的一致性；[results.json](results.json) 保存每个输入文件 SHA256、每题五路候选来源、依赖命中和逐题增减。不需要私有项目、网络或模型服务。上游文本、排名和标注的许可沿用父实验，尤其 LoCoMo 为 CC BY-NC 4.0。
