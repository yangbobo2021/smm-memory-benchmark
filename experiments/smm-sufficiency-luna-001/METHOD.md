# SMM-SF-LUNA001：充分性判断与一次主动补查

固定模型为 **GPT-6-Luna / high**，通过现有 OpenAI Codex 订阅调用。模型在本次测试中只判断和输出查询，不直接运行工具；外围检索器按其输出执行同一个原始 BM25。模型不见参考答案、依赖清单、参考数量、缺失标记或其他题的历史。

## 固定流程

1. 原始问题运行原 BM25，取前5段完整原对话。各文档保留原始角色、完整正文和时间，不截断、不摘要。
2. Agent 判断充分/缺失，记录支持的简短回答、原文引用、具体缺口；缺失时给出一个新的 BM25 输入。
3. 仅在 Agent 判断缺失时执行补查：原语料、原 BM25 公式和分词，先在全语料打分，再排除前5段，取另外最多5段。不是删掉前5段后重建索引，不改变 IDF。
4. 若有新增对话，把原5段、新增最多5段及先前判断交给同一模型档位的新隔离调用，再判断充分性。保留完整可见历史，但不复用不可见思考。不执行第三轮查询。

原25、后续32和LoCoMo200题均运行，共257题。主流程最多514次逻辑调用，实际次数随 Agent 是否要求补查而定；仅429后等待30秒重试同一输入一次；不按成绩重抽。底层 Codex 运行时的网络重试不可观测，逻辑调用数不等于底层HTTP尝试数。每次尝试的失败与超时分别保留，成功重试不得抹去首次429。

先前Luna high独立试跑P01、C037、L011、P07的同字节输入和真实输出按哈希复用；其历史45秒间隔仅影响墙钟，后续调用不设固定间隔。所有重试收据另存，单线程执行。

## 两种评估口径

**保持不变的官方引用口径**：原BM25 Top5为201题参考取齐、56题未取齐。该口径覆盖全部257题，但不能把缺一段背景、缺一个重复引用等同缺少答案。

**本轮运行前审核的回答依赖口径**：原25题沿用已标注必要证据；后续题检查问题、官方参考原句与必要上下文，合并重复支持，去除不必要背景，允许事先记录的替代证据。每个依赖单元列出可支持它的来源集合，必须所有单元被覆盖才判“标注依赖齐全”。审核发生在正式推理之前，文件与SHA已冻结。

例如：

- 当前明确说有4辆自行车，无需额外读到旧的3辆记录才能回答当前数量。
- 问是否结婚时，一段明确提到丈夫的记录可能已经足够，无需找到所有4段重复引用。
- Tilly何时获赠则仍需日期与后来名称关联两段，不能统一删掉第二段。
- C135的官方来源不对应Phuket退修，本轮依赖口径预先记录正确来源；官方口径保持原标签。
- 原文中的伤病、海滩居住推断、未知照片内容、同人称归属、计划与实际混淆等25道歧义题不进入“明确依赖条件下判断准确率”的分母，但全部执行、保留，并报告其官方口径结果。

冻结后，明确依赖条件为199题齐全、33题缺失；另25题歧义单列。审核由本研究作者完成，**不是外部独立人类金标**，不能证明已穷尽所有可替代原文。若后续人工复核模型证据发现别的有效依据，将另行披露补充审计，不悄悄更改冻结主分。

## 指标

分三个数据组，分别报告：

- 给定依赖齐全：判断充分的比例；不必要补查的比例。
- 给定依赖缺失：判断缺失的比例；过早停止的比例。
- 真缺失且发起补查：新Top5补到至少一个缺失单元、补齐全部依赖的比例。
- 所有初始缺失题：最终补齐的比例。过早停止的题也留在分母，不能只报“愿意补查的成功题”。
- 补查后依赖齐全/仍缺失：第二次判断是否正确，以及补齐后仍继续找的情况。
- 模型实际查询、完整排名、无重复检查、完整输入/首输出、引用字面合法性、错误、用量与耗时。

不报告最终回答正确率。输出中的短回答与引用用于复核其判断，并不是已经按原答案完成作答验收。

## 不能忽略的限制

“依赖事实上齐全”和“Agent能从有限结果证明再无其他相关事件”不是同一件事。对于没有总数声明、隐藏事件也没有任何线索的历史计数题，Agent无法凭空知道是否还漏了一个事件。这里测试的是对固定证据标签的停止与补查行为，不是证明可以一般性解决未知信息是否穷尽。
