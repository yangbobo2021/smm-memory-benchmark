# 稳定范围、人物索引、事件词和时间：12 题小规模验证

用户问：如果把稳定的用户／知识空间／人物 ID、人物在文档中的角色，以及事件词和时间都纳入检索，Top5 的**至少命中一条**与**取齐全部官方引用**会怎样？这里先用已归档语料做一个可重放的机制测试。12题和排序规则在运行前写入[协议](protocol.json)，原问题、1000段候选、原文、官方引用、BM25实现均未改；关键词来自在1000段扩库前写好的[旧输入](../smm-query-input-001/authored-inputs.tsv)，没有本轮新模型调用。

本实验把来源 `provenance.sample_id` 当作**调用方已知的知识空间 ID**，题目 `family` 是查询请求带入的对应 ID，同时用 `known_at` 排除未来会话。它是 LoCoMo 的**对话家族 ID**，比真实应用的用户 ID 更窄；不能声称系统自动识别了正确用户或人物。范围内用 `sample_id:姓名` 做临时人物键，分别记录说话人和正文精确提及；这还不是经过消歧的真实 person_id。

## Top5／Top10 的结果

| 候选范围与排序 | Top5 至少一条官方引用 | Top5 取齐全部官方引用 | Top10 取齐全部官方引用 |
|---|---:|---:|---:|
| 1000段全库，原问题BM25 | 5/12 | 3/12 | 6/12 |
| 已知 `sample_id` 范围，原问题BM25 | 7/12 | 4/12 | 4/12 |
| 已知范围，旧关键词输入BM25 | 9/12 | 7/12 | 9/12 |
| 已知范围＋人物的说话／提及入口，原问题BM25 | 7/12 | 4/12 | 4/12 |
| 已知范围＋人物入口，旧关键词输入BM25 | 9/12 | 7/12 | 9/12 |
| **已知范围＋人物入口＋旧关键词＋显式日期轻量加分** | **10/12** | **8/12** | **9/12** |

“命中”严格指至少一条**官方引用来源 ID**进入 Top5；“取齐”严格指全部官方引用 ID 进入 Top5，均非最终答案正确率。本12题是按机制有意选取的已知例，不是随机或盲测样本。原范围每题只有25–32段，且恰好等于该题先前的小语料；所以这组结果**没有证明同一个用户积累1000段后的准确率**。

## 哪一层真正起作用

- **范围约束有用，但这里的范围过于理想。** `sample_id + known_at` 机械地从1000段取回各题25–32段旧历史，12题官方引用全部保留。它删除跨对话家族／跨人物干扰。第一人称的 P20/L028 更能说明背景：各自官方来源在混合1000段排第23/115，在各自原题历史排第1/5。现实应用可以用已知登录用户或知识空间 ID 隔离权限与候选，但若需要跨空间证据，不能擅自硬过滤。
- **旧关键词输入贡献最大。** 在已知范围内，它将取齐从4/12升到7/12；C183 的两条官方来源从第4、16到第1、2，C037 的三条从第14、12、4到第3、2、1。C157、C051依然漏检，说明同范围内仍有多证据排序问题。关键词由研究者事先编写，不能把此幅度当成真实 Agent 自动改写的保证。
- **这批题里人物入口没有增加命中数。** 10题查询的是交谈双方；范围内每段会话都有相应说话人，所以人物条件没有缩小候选。C184 问 Deborah 何时认识 Anna：Anna 在 6/30 段里被**提到**，从未说话；C195 问 James 何时向 Samantha 表白：Samantha 在3/31段里被**提到**，也从未说话。两题官方来源都属于仅提及入口；若只索引“本人发言”，会把正确来源删光。本两题官方来源原本已排第一，人物入口只证明保留路径、没有产生额外准确率收益。
- **显式日期小幅加分使一题跨过 Top5。** 协议固定：只有问句含英文月份＋年份且能确定具体日或月初1–10日时，来源 `received_at` 落在区间内的 BM25 分数乘1.25，不做硬过滤。C088 问9月8日 Jolene 为何改期，官方来源第10→第3；C118 问11月初 Nate 赢什么比赛，第5→第2；C046 的来源第3→第2。其余9题未触发。这个规则只测试3道显式时间题，且基准来源日期恰与事件日期接近；不能推广到“下周”、回忆很久以前的事件或多段跨时证据。

最终方案比全库原问题多取齐5题：C183、C152、C118、C037、C088，没有在本12题的官方 Top5 取齐指标上造成退化。但这不等于5道题从答错变答对：C152 原 Top5 第2段已明确给出椰奶配方；C183 虽两条官方来源排前，仍需核查是否真能推出“受伤两次”；C129 虽未取齐四条官方引用，原 Top5 一条“我在那里结婚”已足以回答。C118 的原文明确说明 Nate 赢的是 Valorant，本轮组合确实把它从第27推到 Top5；C088 则把改期理由的官方原文推入Top5。

## 结论边界

这12题支持：**调用方已知的范围 ID、能体现事件约束的查询词、软性的显式时间信号**可以互补；把“说话人”和“仅被提及”分开记录是避免误删所必需的。但本次**没有验证稳定 person_id 消歧算法**，人物入口在范围内没有带来额外命中。也不能把对话家族 ID 直接等同真实用户 ID，或把25–32段历史中的结果当作1000段同一用户历史中的结果。下一项有价值的检验应是有真实归属 ID、跨较长时间积累且包含同名与第三方人物的事件流；在那之前，不应宣布完整方案已被验证。

复现：`python3 -B experiments/smm-scoped-person-time-pilot-001/run.py --verify`。它逐题重算12题所有排名，核对原文SHA、来源范围、旧原问题／关键词排名和原1000段Top10。全部原始排名与详细命中位置见[results.json](results.json)；原1945个冻结基线文件、750条模型逻辑记录保持不变。
