# 更正验证：不使用 `sample_id`，始终从完整1000段对话检索

用户指出前一轮以 `sample_id` 模拟调用方已知知识空间，会把每题1000段缩至25–32段，不能回答真正的1000段检索问题。本轮按此约束重跑：**每种方法均从同一冻结的1000段原生对话开始**，候选过滤和排序不读取 `sample_id`、题目家族、原始／干扰分组或官方参考。唯有问句中固定的人名、原文说话人／姓名整词出现、此前发布的关键词输入和原文时间可参与检索。12题及方法在运行前固定于[协议](protocol.json)；[逐题结果](results.json)保留完整 Top10、官方引用排名与过滤规模。

“命中”=Top5 至少包含一条**官方引用对话**；“取齐”=Top5 包含该题所有官方引用对话。这仍是来源指标，不是最终答案正确率。12题为已知机制例，不能当成随机样本准确率。

| 完整1000段起点的方案 | Top5 命中 | Top5 取齐 | Top10 取齐 |
|---|---:|---:|---:|
| 原问题 BM25，无人物过滤 | 5/12 | 3/12 | 6/12 |
| 旧关键词输入 BM25，无人物过滤 | 7/12 | 5/12 | 9/12 |
| 原问题 BM25，按说话人或姓名提及过滤 | 7/12 | 4/12 | 4/12 |
| 旧关键词输入 BM25，按人物过滤 | 9/12 | 7/12 | 9/12 |
| 旧关键词输入，无人物过滤，显式日期加分 | 9/12 | 7/12 | 9/12 |
| **旧关键词输入＋人物过滤＋显式日期加分** | **10/12** | **8/12** | **9/12** |

这组数字与上一次范围实验的末行碰巧相同，**机制却不同**；上一次使用了不可用的 `sample_id` 范围，本次完全没有。两者不能合并或用前次作为本次证据。

## 实际怎样匹配人物和时间

问句人名是这12题预先列出的工具参数，仍未验证 Agent 能稳定抽取。索引先取原文结构里的 `speaker`，另用原文整词匹配 `mentioned name`；满足任一条件即保留该整段对话。没有自动消歧、别名合并或真正稳定的 `person_id`。例如 **John** 在1000段里仍匹配95段，包含多个不同 John；C051 的两条官方参考在最终排序只排第14、36，说明同名与同人多事件问题仍在。

第三方人物必须可由提及入口找回：C184 的 Anna 出现在6/1000段、C195 的 Samantha 出现在3/1000段，两人都不是这些对话的说话人；各自官方引用分别排第1。只索引“本人发言”会把这两个正确来源全部删掉。另一方面，在这套数据中 Nate 只对应29段、Deborah只对应30段，姓名条件几乎直接隔离了一个对话家族，这是语料特性，不能推断大库中的同名人物也如此。

时间规则仅处理英文问句中明确的“月份＋年份”，有日则匹配当日，`beginning/early` 匹配该月1–10日；候选来源 `received_at` 落在区间内时 BM25 分数乘1.25。它**只加分、不按时间删文档**；无时间戳的来源不加分。12题中只有 C118、C088、C046 触发。C088 的官方来源在旧关键词全库第10，加分后第2，首次进Top5；C118 的 Valorant 原句第7→第2；C046 第5→第1。这个固定启发式恰与本数据的会话日期一致，不能推广到事后回忆或相对日期。

## 具体收益和仍未解决的题

- C152 问 Nate 的无乳糖冰淇淋材料：旧关键词全库的官方引用第6，人物过滤后第4。不过原 Top5 第2段已明确给出椰奶配方，这只是官方 ID 指标改进，并非答案从无到有。
- C118 问 Nate 2022年11月初赢哪项比赛：原问题全库的正确 Valorant 原文第27；旧关键词全库第7；人物过滤或日期加分分别使它进Top5，组合到第2。这里 Top5 确有新出现的直接答案证据。
- C183 问 John 脚踝受伤几次：旧关键词**即使不加人物过滤**，两条官方来源已排第3、第1；人物过滤变第1、第2。姓名过滤清除一部分错人对话，但不能证明次数推理本身正确。
- C170、C157、C051 最终仍未取齐；前者多段都谈乌龟但数量证据未齐，后两题涉及多人或多地点的分散证据。C129 四条官方引用也未取齐，不过原Top5已有 Deborah 自述结婚的充分原句。

所以在这12题中，**关键词输入和日期是主要增益来源，人物姓名过滤也有局部贡献**；“稳定人物 ID + 关系角色”这个更强的设计尚未被验证。本轮只验证了基于字面姓名的 speaker/mention 过滤。尤其不能据10/12、8/12宣称一般的1000段知识库达到83%/67%：题目是事先挑选的，数据中多数姓名罕见，且官方引用可能冗余或缺标。

复算：`python3 -B experiments/smm-person-time-1000-pilot-001/run.py --verify`。12题原文SHA与原1000段BM25 Top10绑定均通过，无模型调用、无gold驱动的重排。前一轮使用 `sample_id` 的实验作为历史上界诊断保留，但不再作为目标方案成绩。
